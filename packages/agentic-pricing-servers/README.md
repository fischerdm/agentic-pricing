# agentic-pricing-servers

Shared server infrastructure for exposing agentic insurance pricing services.

Part of [agentic-pricing](https://pypi.org/project/agentic-pricing/), the shared
foundation for agentic AI in insurance pricing. This package is at an early stage.

## Installation

```bash
pip install agentic-pricing-servers
```

```python
import agentic_pricing.servers
```
